# BAND MANAGER
밴드 운영 및 공연 기획 플랫폼

밴드를 만들고 멤버와 곡을 관리하며, 공연 세트리스트와 가상의 음악 페스티벌까지 기획하는 웹사이트입니다.
단순한 정보 관리가 아니라 **세트리스트 편집 → 공연 시간 계산 → 페스티벌 타임테이블 제작**처럼 실제 공연을 기획하는 과정을 직접 조작하며 진행하는 데 중점을 둡니다.

---

## 실행 방법
- 빌드나 설치가 필요 없습니다. **`index.html`을 더블클릭**해 브라우저로 열면 바로 실행됩니다.
- 처음 열면 예시 데이터(밴드 2팀, 곡 9곡, 후보곡 2곡, 합주 3회, 페스티벌 1개)가 들어 있어 모든 화면을 바로 둘러볼 수 있습니다.
- 데이터는 **지금 쓰는 브라우저에만 저장**됩니다(localStorage). 다른 기기·브라우저와 공유하려면 아래 [Supabase 연결](#supabase-연결)을 참고하세요.
- 화면 맨 아래 **reset demo**를 누르면 모든 데이터가 지워지고 예시 데이터로 돌아갑니다.
- 인터넷 연결이 필요한 기능: 글꼴, 캘린더(FullCalendar), iTunes 곡 검색·미리듣기, Supabase 동기화. 오프라인에서도 나머지 기능은 동작합니다.

## 화면 구성
| 메뉴 | 주소 | 내용 |
|---|---|---|
| Home | `#/home` | 서비스 소개, 대시보드(다음 합주·최근 세트리스트·페스티벌) |
| My Bands | `#/bands` | 내가 운영하는 밴드 목록, 밴드 생성·삭제 |
| Studio | `#/studio` | 선택한 밴드의 곡·진행도·후보곡·멤버·활동 기록 |
| Setlist | `#/setlist` | 곡 라이브러리와 공연 세트리스트 제작 |
| Rehearsal | `#/rehearsal` | 합주 일정(날짜+시간), 참석 체크, 공연 이력, 통계 |
| Progress | `#/progress` | 곡별 연습 진행도와 멤버별 과제 전체 보기 |
| Festival | `#/festivals` | 페스티벌 목록과 생성 |
| Timetable | `#/timetable` | 현재 페스티벌의 무대별 시간표 |
| Personal | `#/personal` | 관객 입장의 개인 관람 시간표 |

페스티벌 상세는 `#/festival/:id/(overview|lineup|timetable|poster|stage)` 탭으로 나뉩니다. `:id` 자리에 `active`를 쓰면 현재 선택된 페스티벌이 열립니다.

오른쪽 위 **active band** 선택창으로 작업할 밴드를 바꿉니다. Studio·Setlist·Rehearsal·Progress는 선택된 밴드 기준으로 표시됩니다.

## 기능 안내

### ① My Bands — 밴드 목록
- **+ 새 밴드**: 이름, 장르, 소개, 대표 색상, 로고 이미지 등록
- 카드를 누르면 그 밴드가 선택되고 Studio로 이동
- 카드에 마우스를 올리면 오른쪽 위에 **✕ 삭제 버튼**이 나타납니다(휴대폰에서는 항상 표시)
  - 삭제하면 그 밴드의 곡·세트리스트·합주 일정·과제·공연 기록이 함께 지워집니다. 삭제 전 확인 창이 뜹니다.
  - 선택 중인 밴드를 지우면 남은 밴드로 자동 전환됩니다.

### ② Band Studio — 밴드 안에서 관리
상단에 밴드 이름이 흐르는 배너와 멤버·곡·합주·공연 수가 표시됩니다.

**Songs & Progress (곡 추가 + 펼쳐보는 진행도)**
- **+ 곡 추가**로 현재 밴드에 바로 곡을 넣습니다.
- 곡 줄을 누르면 **아래로 펼쳐지며** 다음 내용을 보여줍니다(한 번에 한 곡만 열림).
  - 곡 정보: 아티스트, 길이, BPM, 난이도, 분위기, 이 곡이 들어간 세트리스트
  - 연습 진행도 슬라이더(100% = 무대에 올릴 준비 완료)
  - 이 곡의 연습 과제 체크·삭제, 멤버를 골라 과제 추가
  - 곡 정보 수정, 세트리스트로 이동

**Candidates (후보곡)**
- 아직 확정하지 않은, 해보고 싶은 곡을 후보로 올리고 멤버 투표로 정합니다.
- **+ 후보곡**: 제안한 멤버와 추천 이유를 함께 기록할 수 있습니다.
- 멤버 이니셜 동그라미를 누르면 그 멤버의 찬성 표가 켜지고 꺼집니다. 표가 많은 곡이 위로 정렬됩니다.
- 멤버 절반 넘게 찬성하면 **과반** 표시와 라임색 강조가 붙습니다.
- **확정**을 누르면 정식 곡 목록으로 옮겨져 세트리스트와 진행도에서 사용할 수 있습니다.
- iTunes 검색으로 추가한 곡은 **▶ 버튼으로 30초 미리듣기**가 됩니다.
- 후보곡은 Setlist·Progress 화면에 나타나지 않습니다.

**Members / Activity Log**
- 멤버 추가, 이름·악기·포지션 바로 수정, 삭제
- 날짜별 활동 기록 추가·삭제

### 곡 추가 창 (공통) — iTunes 곡 검색
Studio의 **+ 곡 추가 / + 후보곡**, Setlist의 **+ 곡 등록**에서 같은 창이 열립니다.
1. 맨 위 검색칸에 곡명이나 아티스트를 입력하고 Enter → 결과 최대 12개(앨범 커버, 곡명, 아티스트·앨범, 길이)
2. 결과를 누르면 **곡명·아티스트·길이**가 자동으로 채워지고 앨범 커버와 미리듣기 링크가 저장됩니다.
3. **BPM은 iTunes가 제공하지 않으므로 직접 입력**합니다(검색 후 커서가 BPM 칸으로 이동).
4. 난이도(1~5), 분위기(Calm·Groove·Hype·Ballad)를 고릅니다.
5. **"후보곡으로 등록"** 체크박스로 후보곡/정식 곡을 전환합니다.

> 참고: iTunes 한국(KR) 스토어는 검색 결과가 0건이라 미국(US) 스토어를 사용합니다. 한글로 검색해도 찾아지지만, 곡명·아티스트가 영어로 들어오는 경우가 많습니다(예: 잔나비 → JANNABI). 필요하면 채워진 뒤 한글로 고쳐 저장하세요. 검색에 실패하면 직접 입력하면 됩니다.

### ③ Setlist Maker
- **Song Library**: 확정된 곡 목록. 줄을 끌어서 오른쪽 세트리스트에 넣거나 ＋ 버튼으로 추가합니다.
- **세트리스트**: 여러 개 만들고 선택창으로 전환, 이름 변경·삭제
- 곡을 **끌어서 순서 변경**, ✕로 빼기
- **공연 시간 자동 계산** = 곡 길이 합 + 곡 사이 전환 시간 × (곡 수 − 1) + 곡별 멘트(MC) 시간
- **제한 시간(분)**을 넘으면 초과 시간을 경고하고, 시간 안에 못 들어가는 곡을 흐리게 표시합니다.
- **⚡ 자동 구성**: 연습 진행도가 높은 곡부터 제한 시간에 맞게 고르고, "에너지 있게 시작 → 중반은 잔잔하게 → 가장 센 곡으로 마무리" 순서로 배치합니다.
- **Show Flow**: BPM(막대 높이)·분위기(색)·곡 길이(막대 너비)로 공연 흐름을 보여줍니다.

### ④ Rehearsal — 합주 일정 (날짜 + 시간)
**캘린더**
- 기본은 **주간 보기**(08:00–24:00 시간 칸). 오른쪽 위에서 주 / 월 / 목록 보기로 바꿀 수 있습니다.
- **시간대를 마우스로 끌어서 선택**하면 그 날짜·시작·종료 시간이 채워진 등록 창이 뜹니다. 한 번만 누르면 그 시각부터 3시간으로 잡힙니다.
- 월 보기에서 날짜를 누르면 그 날짜로 등록 창이 뜹니다.
- 등록된 합주 블록을 **끌어서 날짜·시간 이동**, **아래 끝을 끌어서 길이 조절**이 됩니다. 자정을 넘기는 이동은 막혀 있습니다.
- 일정을 누르면 수정 창이 열립니다. 보라색은 공연 기록입니다.

**합주 등록 창**
- 날짜, 시작, 종료 시간 모두 필수
- 빠른 선택 버튼: 오전 10–13, 오후 14–17, 저녁 19–22, 심야 22–24
- 총 합주 시간을 바로 보여주고, 종료가 시작보다 빠르면 경고합니다.
- 연습실·장소(이전에 쓴 장소 자동완성), 멤버별 참석/미정/불참, 메모

**그 밖에**
- Upcoming: 다가오는 합주와 참석 인원
- Attendance Rate: 지난 합주 기준 멤버별 참석률
- Places: 장소별 이용 횟수
- Show History: 공연 기록(제목, 날짜, 장소, 메모, 사진 여러 장)
- 상단 통계: 진행한 합주 수, 총 합주 시간, 예정 합주 수, 공연 수

### ⑤ Progress
- 확정된 모든 곡의 진행도를 낮은 순으로 한눈에 보고 슬라이더로 조정
- 멤버별 연습 과제(곡 연결 선택 가능) 추가·체크·삭제
- 곡 하나씩 자세히 보려면 Studio의 Songs & Progress에서 곡을 펼치면 됩니다.

### ⑥ Festival Maker
- **+ 새 페스티벌**: 이름, 시작일, 기간(1–5일), 장소, 테마, 운영 시간, 기본 장비 교체 시간, 포스터 색상
- **Overview**: 정보 수정, 무대 추가·이름·색상 변경·삭제, 통계
- **Lineup**: 출연진 추가(REAL 실제 밴드 / VIRTUAL 가상 밴드), **내 밴드 불러오기**, ★ 헤드라이너 지정, 배치 현황
- **Timetable**
  - 왼쪽 라인업을 무대 칸으로 끌어다 놓으면 배치(기본 45분). 라인업을 클릭해 시간을 직접 입력해도 됩니다.
  - 블록을 끌어서 시간·무대 이동, 아래 끝을 끌어서 길이 조절(5분 단위)
  - 블록을 누르면 시간·길이·공연 후 장비 교체 시간을 수정하고, 이 공연의 무대 구성으로 이동할 수 있습니다.
  - 빗금 영역 = 장비 교체 시간
  - **충돌 검사**: 같은 무대 공연 시간 겹침, 장비 교체 시간 부족, 한 밴드의 두 무대 동시 배치, 운영 시간 벗어남을 자동으로 찾아 보라색으로 표시합니다.
- **Poster**: 라인업·헤드라이너·날짜·장소로 포스터를 자동 생성
  - 템플릿 2종: **Ripple**(주황+보라 물결 글씨), **Grid**(초록+검정 대형 타이포)
  - 배경·강조 색 변경, **PNG 저장**, **공유**(지원 기기에서는 공유 창, 아니면 다운로드)
- **Stage Designer**: 드럼, 기타 앰프, 베이스 앰프, 마이크, 키보드, 모니터, PA, DI를 무대 위에 배치
  - 끌어서 이동, 더블클릭이나 ↻ 버튼으로 45° 회전, Delete 키로 삭제, 자동 저장
  - 무대별 기본 구성 + **공연별 전용 구성**(공연을 고르고 편집하면 그 공연 전용으로 저장)
  - 아래에 장비 목록과 개수 표시

### ⑦ Personal Festival — 관객 모드
- 날짜별 전체 공연 목록에서 보고 싶은 밴드에 **★ 즐겨찾기**
- 즐겨찾기한 밴드만 모은 **내 시간표**: 공연 사이 여유 시간, 무대 이동 여부 표시
- 시간이 겹치는 공연은 보라색으로 경고
- **텍스트 복사**(메신저 공유용), **이미지 공유**(시간표 이미지 생성)

## 기술 구성
- **Frontend**: HTML, CSS, 순수 JavaScript (빌드 없음, `file://`로 실행 가능)
- **Drag & Drop**: HTML Drag and Drop API(세트리스트, 라인업 배치) + Pointer Events(타임테이블 블록, 무대 장비)
- **Calendar**: FullCalendar 6.1.15 (주/월/목록, 시간대 선택, 일정 드래그)
- **Visualization**: CSS Grid (공연 흐름, 타임테이블)
- **Poster / 시간표 이미지**: HTML Canvas
- **곡 검색**: iTunes Search API (키 불필요, JSONP 호출)
- **Backend (선택)**: Supabase


## Supabase 연결
1. Supabase 프로젝트의 SQL Editor에서 `supabase/schema.sql`을 실행합니다.
2. `js/config.js`에 `SUPABASE_URL`, `SUPABASE_ANON_KEY`를 입력합니다.
3. 새로고침하면 전체 데이터가 `app_state` 테이블과 자동 동기화됩니다. 같은 `WORKSPACE_ID`를 쓰는 브라우저끼리 데이터를 공유합니다.

> 주의: 현재 정책은 키를 아는 누구나 읽고 쓸 수 있는 **데모용**입니다. 실제 서비스로 쓰려면 Supabase Auth로 로그인을 붙이고 `auth.uid()` 기반 정책으로 바꿔야 합니다. Supabase 연결은 코드만 준비되어 있고 실제 프로젝트에 연결해 시험하지는 않았습니다.

## 알려진 한계
- 데이터가 브라우저에 저장되므로 사진을 많이 올리면 저장 공간(약 5MB)이 부족할 수 있습니다. 사진은 자동으로 줄여 저장합니다.
- iTunes는 BPM을 제공하지 않습니다.
- HTML Drag and Drop은 터치 기기에서 동작하지 않습니다. 휴대폰에서는 세트리스트의 ＋ 버튼, 타임테이블의 라인업 클릭으로 대신 추가할 수 있습니다(타임테이블 블록·무대 장비 이동은 터치도 지원).
