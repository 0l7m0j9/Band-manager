# BAND MANAGER
학교 밴드 운영 플랫폼 — 그룹(학교) 안에서 밴드·곡·세트리스트·합주·연습실·공연(페스티벌)·게시판을 함께 관리합니다.

---

## 처음 설정 (관리자 1회)
1. Supabase 프로젝트의 **SQL Editor**에서 `supabase/schema.sql` 전체를 실행합니다. 여러 번 실행해도 안전합니다.
   - `김포 고등학교` 그룹과 기본 연습실 `음악실`이 만들어집니다.
2. Authentication → Sign In / Providers → Email 에서 **Confirm email**을 끕니다. 앱은 메일을 쓰지 않습니다.
3. 앱에서 관리자가 될 계정으로 **회원가입**합니다.
4. SQL Editor에서 한 줄을 실행해 최초 관리자를 지정합니다. 아이디는 앱 코드에 넣지 않고 여기서만 씁니다.
   ```sql
   select public.bootstrap_admin('가입한_아이디');
   ```
5. 이후 공동 관리자는 앱의 **Members → 회원 선택 → 공동 관리자로 지정**으로 추가합니다.

`js/config.js`의 Supabase 주소·공개 키는 이미 들어 있습니다.

## 계급과 메뉴
| 계급 | 정하는 방법 | 상단 메뉴 |
|---|---|---|
| **관리자** | 최초 관리자(SQL) / 관리자가 지정 | Home · Bands · Calendar · Rooms · Festival · Board · Members |
| **단장** | 밴드를 만든 사람, 또는 단장이 지정한 밴드원 | Home · Bands · Calendar · Rooms |
| **부원** | 그 외 모든 회원 | Home · Bands · Calendar |

권한이 없는 메뉴는 주소로 직접 들어가도 Home으로 돌아갑니다. 실제 권한은 서버(Supabase RLS)가 검사하므로, 화면을 우회해도 데이터는 바뀌지 않습니다.

### 회원가입 → 그룹 → 밴드
- 회원가입 때 **아이디·비밀번호·이름·악기(여러 개)·전화번호·그룹**을 입력합니다. 그룹 참여는 필수이고 바로 가입됩니다.
- 전화번호는 **본인과 관리자만** 볼 수 있습니다.
- **Bands**에서 그룹의 모든 밴드를 볼 수 있고, **가입 신청** → 단장이 승인하면 밴드원이 됩니다.
- 누구나 **새 밴드**를 만들 수 있고, 만든 사람이 단장이 됩니다.

## 화면
### Home (모두)
- **Board**: 관리자가 올린 공지·게시글(사진 포함). 눌러서 전체 보기
- **작은 달력**과 **D-day**: 다가오는 합주·공연·연습실 예약·그룹 일정·개인 일정
- **Festival**: 관리자가 **공개로 켠 항목만** 보입니다 (포스터·라인업·시간표·무대 배치·셋리스트·정보)

### Bands
- 위: 내가 속한 밴드(관리자는 전부) / 아래: 그룹의 모든 밴드 → 가입 신청·취소
- 밴드를 누르면 **Studio · Setlist · Rehearsal · Progress** 탭
  - **부원**: 모든 내용을 **보기만** 합니다 (화면에 "보기 전용")
  - **단장·관리자**: 곡·세트리스트·합주·과제·공연 기록·밴드 정보 수정, **가입 신청 승인/거절**, 밴드원 파트·포지션·단장 지정, 내보내기
  - **관리자**: 밴드 삭제
- 예전 기능(곡 검색·후보곡 투표·세트리스트 자동 구성·공연 흐름·합주 캘린더·진행도)은 그대로 있습니다.

### Calendar (모두)
- 월 달력에서 날짜를 누르면 그날의 **시간표**가 나옵니다 (아이폰 캘린더처럼). 빈 시간을 누르면 그 시간으로 일정 추가
- **개인 일정**(짙은 회색) → **밴드 일정**(합주·공연·확정된 연습실 예약) → **그룹 일정**(가장 옅은 회색, 공개 페스티벌 포함)
- 수정할 수 있는 것은 **개인 일정**뿐입니다. 관리자는 그룹 일정도 추가·수정합니다.

### Rooms (단장·관리자)
- **단장**: 내가 단장인 밴드 이름으로 날짜·시간·연습실을 골라 **예약 신청** → 관리자 승인 후 확정. 대기 중 신청은 취소 가능
- **관리자**: **승인 대기** 목록에서 승인/거절, 모든 밴드의 일정 **직접 추가**(바로 확정)·삭제, **연습실 목록** 관리
- 같은 연습실·같은 시간에 확정된 예약이 겹치면 서버가 막습니다.

### Festival (관리자)
- 페스티벌마다 **Overview · Lineup · Timetable · Poster · Stage Designer · Setlists** 탭
- 위쪽 **공개 스위치**(정보·라인업·시간표·포스터·무대 배치·셋리스트)를 켠 항목만 회원 Home에 보입니다.
- **Setlists**: 출연 밴드의 세트리스트를 골라 공개용으로 저장합니다. 밴드가 고친 뒤에는 "최신으로"를 누르세요.
- 포스터: 레이아웃 6종·패턴·글꼴·색 편집, 🎲 랜덤, ✦ AI 시안(아래 설정 필요)

### Board (관리자)
- 글·사진(최대 4장) 올리기, 수정, 삭제, 공지 고정

### Members (관리자)
- 그룹 참여자 명단: 이름·아이디·악기·소속 밴드·전화번호
- 통계(전체·관리자·단장·밴드 없음), 악기별 인원 — 누르면 그 악기 회원만
- 검색(이름·아이디·악기·밴드), 필터(전체 / 관리자 / 단장 / 밴드 없음)
- 회원을 누르면 관리 창:
  - **공동 관리자 지정/해제** (마지막 관리자는 해제 불가)
  - **밴드에 바로 넣기**(부원/단장, 신청·승인 없이), 밴드에서 빼기, 단장↔부원 변경
  - **그룹에서 내보내기** (그 그룹의 밴드 소속·개인 일정도 정리)
- **스프레드시트로 내보내기**: 회원·밴드·밴드원·곡·세트리스트·합주·연습실 예약·그룹 일정 중 골라서
  - **.xlsx 받기**: 표마다 탭으로 나뉜 파일 하나 → 구글 드라이브에 올려 열면 구글 시트 (엑셀에서도 열림)
  - **복사**: 표 하나를 복사 → **새 구글 시트**에서 A1 칸에 붙여넣기
  - 회원 표는 지금 Members 화면의 검색·필터 결과 기준

### Account (모두)

## 예전 데이터
예전 버전(친구 공유 방식)의 데이터와 코드는 지우지 않고 보관합니다.
- **코드**: git 브랜치 `v1-backup`
- **데이터**: Supabase `app_state` 표(예전 계정 데이터)와 각 브라우저의 저장 데이터
- 필요할 때 **Bands → 예전 데이터 가져오기**(또는 Account)에서 밴드·페스티벌을 골라 새 구조로 **복사**합니다. 원본은 그대로 남습니다.
  - 밴드를 가져오면 내가 단장이 됩니다. 예전 멤버는 회원 계정이 아니라서 과제에는 `[이름]`으로 남고, 합주 참석 기록은 비워집니다.
  - 페스티벌은 관리자만 가져올 수 있습니다.

## AI 포스터 설정 (선택)
1. [Supabase CLI](https://supabase.com/docs/guides/cli)로 `npx supabase login` → `npx supabase link --project-ref <프로젝트 ref>`
2. `npx supabase secrets set ANTHROPIC_API_KEY=sk-ant-...`
3. `npx supabase functions deploy poster-ai`
- 로그인한 회원만, 하루 20회까지. 모델은 `claude-opus-5-5`입니다.
- 설정하지 않아도 🎲 랜덤과 직접 편집은 쓸 수 있습니다.

## 기술 구성
- **Frontend**: HTML · CSS · 순수 JavaScript (빌드 없음). Netlify 등 정적 호스팅
- **Backend**: Supabase — Auth(아이디 로그인), Postgres + RLS(계급별 권한), Realtime(다른 사람의 변경이 바로 반영), Edge Function(AI 포스터)
- 밴드 내용·페스티벌은 문서(JSON) 단위로 저장하고 버전(`rev`)으로 충돌을 감지합니다. 두 사람이 동시에 고치면 항목(곡·세트리스트 등) 단위로 합칩니다.

## 알려진 한계
- 사진(로고·공연·게시판)은 데이터에 함께 저장되어 많아지면 느려질 수 있습니다. 많아지면 Supabase Storage로 옮기는 것을 권합니다.
- HTML 드래그 앤 드롭은 터치에서 동작하지 않아, 휴대폰에서는 ＋·▲▼ 버튼을 씁니다.
- iTunes는 BPM을 제공하지 않습니다.
